# Alien Field Notes: The Two Day Earth Review

A one-line entry for the make.fun competition "Alien Field Notes: The Two Day Earth Review": a review of planet Earth left by an alien tourist, in at most 200 characters.

The program in `main.py` writes the entry text to `/output/entry.txt`, where the competition's sealed scorer reads it.

Competition: https://make.fun/api/competitions/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000/requirements

## Entry

Earth: stunning views, generous hosts, but the Wi-Fi password is a state secret and the locals queue for everything. Three stars.
